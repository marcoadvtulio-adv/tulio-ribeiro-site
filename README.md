# Marco Túlio Ribeiro Advocacia — redesign

Site institucional estático, sem framework e pronto para publicação no GitHub Pages.

## Sistema visual

- **Ink** `#07101e` e **Navy** `#0d1c2f`: base institucional e tecnológica.
- **Slate** `#1c344d`: planos intermediários e contraste.
- **Gold** `#c9a24d` e **Gold deep** `#a98234`: assinatura e ações.
- **Cream** `#f4efe3`: superfície clara de leitura.
- **Fraunces**: títulos; **Manrope**: texto; **IBM Plex Mono**: referências legais e rótulos.

## Assinatura

A linha dourada de responsabilidade conecta o retrato, a promessa de atendimento direto e as três etapas reais do processo. Ela representa um ponto específico do escritório: o mesmo advogado recebe, analisa e acompanha o caso, sem intermediários.

## Publicação

Publique todos os arquivos desta pasta na raiz do repositório do GitHub Pages. Não há etapa de build.
